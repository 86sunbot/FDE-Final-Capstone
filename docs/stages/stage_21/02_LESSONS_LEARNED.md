# Stage 21 - Lessons Learned

1. The dominant risk was semantic fragmentation, not lack of AI.
2. Source-specific assertions are safer than a falsely authoritative global row.
3. Unknown must be a first-class outcome; empty data is not approval.
4. Authority belongs to authenticated people/policies and exact decisions—not systems, UI fields or model text.
5. Idempotency needs payload, type and scope binding; a random reservation ID is insufficient.
6. Timeout after a possible effect is a reconciliation problem, not a retry signal.
7. A useful deterministic product makes AI optional and safely removable.
8. Writing evaluation thresholds before code prevented demo-driven claims.
9. Synthetic data is useful for invariant/failure tests but cannot establish real value, fairness or production safety.
10. Honest inconclusive evidence leads to a stronger lifecycle decision than invented approval.
