# Target Capabilities, Not Prescribed Technologies

The repo deliberately does **not** require a knowledge graph, digital twin, RAG system or agent. Those are possible interventions. The required capabilities are:

- explainable patient/material/batch identity resolution;
- end-to-end event and decision provenance;
- canonical domain semantics without destroying source evidence;
- contextual journey state and exception prioritization;
- uncertainty-aware forecasts;
- resilient cross-system orchestration with compensation/idempotency;
- governed human authorization for consequential actions;
- measurable operational, safety, quality, cost and reliability outcomes.
