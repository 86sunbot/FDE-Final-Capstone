# Security, Privacy and Assurance Seed Questions

- Which logs/exports expose more patient data than an operational workflow needs?
- Which actions should require explicit human/role authorization?
- How should untrusted notes/documents be separated from instructions to an AI system?
- How should chain-of-identity corrections be proposed, approved, executed and audited?
- Which release and quality decisions must remain outside autonomous agent authority?
- How should evidence, model version, policy version and human approval be captured for TEVV/audit?
